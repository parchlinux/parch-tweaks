# Parch Linux Tweaks

GUI configuration tool for Parch Linux. Manage emoji sets, AUR helpers, editor configs, fonts, and shell setups.

## Install

```bash
sudo pacman -Sy parch-tweaks
```

## Usage

```bash
parch-tweaks  # GUI
ptt           # CLI
```

## Building

```bash
cargo build --release
```

## Packaging

```bash
makepkg -si
```
